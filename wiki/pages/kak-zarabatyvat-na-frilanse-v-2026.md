# Как зарабатывать на фрилансе в 2026, даже если ничего не умеешь

**Source:** https://www.youtube.com/watch?v=5EOOnX1-Pfg
**Date ingested:** 2026-07-24
**Type:** transcript

## Summary

Веб-дизайнер (Дмитрий Варфоломеев) рассказывает свой путь на русскоязычном рынке фриланса
и выстраивает лестницу ниш по возрастанию порога входа — от задач вообще без навыков до
веб-дизайна, которым занимается сам. Центральный тезис: фриланс не имеет потолка по
доходу, и география не имеет значения — например, свой монтажёр видео живёт в Армении,
они ни разу не виделись вживую, но за больше года сотрудничества автор заплатил ему свыше
1 млн рублей.[^1]

**Лестница ниш** (см. [[lestnitsa-frilans-nish](pages/lestnitsa-frilans-nish.md)] для
деталей): работа с текстом без навыков → дизайн карточек для маркетплейсов → обложки для
YouTube → веб-дизайн.[^2]

**Источники клиентов:** сначала друзья и знакомые (низкие ставки, но безопасная
практика реального общения с клиентом), затем биржа фриланса (в источнике — "прору";
характерная деталь — стартовая цена в объявлении часто сильно ниже итоговой: заказы,
на которые автор откликается по 5-15 тыс. руб., после созвона с клиентом закрываются на
75-118 тыс. руб. и выше), затем сарафанное радио как основной постоянный канал.[^3]

**Совет по старту:** лучше начать максимально неподготовленным и получить первый
негативный опыт, чем бесконечно готовиться и откладывать старт из страха отказа.[^4]

## Key Takeaways

- Лестница ниш по возрастанию порога входа: текст без навыков → карточки маркетплейсов →
  обложки YouTube → веб-дизайн.
- География не имеет значения ни для клиентов, ни для исполнителей — пример
  годового сотрудничества с монтажёром из Армении на сумму свыше 1 млн рублей.
- На русскоязычной бирже цена в объявлении часто сильно ниже итоговой суммы после созвона
  с клиентом.
- Порядок каналов клиентов: друзья/знакомые → биржа → сарафанное радио.
- Лучше стартовать неподготовленным, чем откладывать старт из страха.
