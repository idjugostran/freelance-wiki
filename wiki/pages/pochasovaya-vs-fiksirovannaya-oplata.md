# Почасовая оплата vs фиксированная цена

## Description

Два основных формата оплаты на фрилансе (на Upwork — оба доступны как тип контракта; см.
[[upwork](pages/upwork.md)]) имеют разные компромиссы:

- **Почасовая оплата** справедливее, когда объём работы разрастается (клиент просит
  доработки/правки) — фрилансер получает деньги за реально потраченное время. Обратная
  сторона: почасовая ставка ограничивает потолок заработка для быстрого/опытного
  исполнителя — сделать работу вдвое быстрее не означает заработать за неё вдвое больше в
  пересчёте на час.[^1]
- **Фиксированная цена** позволяет опытному фрилансеру зарабатывать существенно больше в
  пересчёте на час, если он выполняет работу быстро (пример источника — $200-300 за
  пару часов). Риск — недооценить объём работы на старте и потерять в почасовом
  эквиваленте, особенно если клиент запрашивает правки сверх изначально согласованного.[^2]

Источник лично комбинирует оба формата, слегка предпочитая фиксированную цену за более
высокий потенциал заработка для быстрого исполнителя.[^2]
