# Почему тебе не доверяют проекты на Upwork — топ ошибок новичков

**Source:** https://www.youtube.com/watch?v=9Su0OehXyN8
**Date ingested:** 2026-07-24
**Type:** transcript

## Summary

Ещё одно короткое видео от URelocate — пять типичных ошибок новичка, почти все из
которых уже зафиксированы в вики другими источниками; отмечаю только то, что уточняет
или добавляет новый нюанс.

**Не занижать цену, чтобы "выиграть" заказ:** западные заказчики (Европа/США)
воспринимают низкую цену как плохой знак, а не как преимущество — это согласуется с
[[konkurentsiya-i-demping](pages/konkurentsiya-i-demping.md)] (не демпинговать даже
будучи новичком).[^1]

**Не использовать один шаблонный cover letter для всех заказов** — подтверждает
[[proposals-cover-letters](pages/proposals-cover-letters.md)].[^2]

**Портфолио должно быть разнообразным и красиво оформленным** — подтверждает
[[portfolio](pages/portfolio.md)]. Новый нюанс: для дизайн-специализаций плохо
оформленный профиль сам по себе сигнализирует заказчику о неспособности хорошо выполнять
дизайнерскую работу — своего рода мета-противоречие (дизайнер с некрасивым профилем).[^3]

**Описание профиля должно быть подробным** (что предлагаете, какие проблемы решаете, в
каких программах работаете, кейсы) — подтверждает содержание
[[kak-zaregistrirovatsya-na-upwork](pages/kak-zaregistrirovatsya-na-upwork.md)].[^4]

**Фото профиля** — убрать фон, использовать приятный однородный цвет — подтверждает
существующие рекомендации по фото профиля.[^5]

## Key Takeaways

- Не занижайте цену — для западных заказчиков это красный флаг, а не преимущество.
- Один шаблонный отклик на все заказы — табу.
- Для дизайн-ниш небрежно оформленный профиль подрывает доверие к вашим дизайнерским
  навыкам сильнее, чем в других нишах.
- Описание профиля и фото — детали, которые часто недооценивают.
